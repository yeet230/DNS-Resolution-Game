The aim of the Game is to drag the bottem square to the correct squares above by matching the IP and Domain name. This must be done within a random timeframe from 7 - 12 seconds.
There will always be one correct and three false squares. getting it correct will give the player 100 points. getting it wrong or having the time run out will result in the player loosing 50 points.

to move the player just move your mouse over the bottem square and click and drag.

There is currently a placeholder CTF_Key in place located inside Globals.gd at line 9 with the value "DNS_H0ST_R34CH3D_SUCCS3FULLY". it will be shown at the end of the 1.5 minite game aslong as the player had 750 or more points.
if they did not achieve the target end scene will prompt them to press "R" to restart.

The Game was devloped in Godot v4.7

The educational goal for this was to show players how a DNS resolution server acts as they must connect a user to the correct ip address/server intime while also avoiding false positives by often malicoius user's
